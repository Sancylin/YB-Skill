# 目标画布与参考隔离

文件身份、默认目标和页名政策来自 [yuanbao-mobile-configuration.md](yuanbao-mobile-configuration.md)。

## 开始前

1. 只枚举目标文件的顶层页名和 ID，不遍历页面内容。
2. 根据配置标记规范源、可写目标、允许参考页和禁止参考页。
3. 本轮目标页即使带禁止参考前缀也可写/评，但不能成为后续参考。
4. 规范源和参考页默认只读。

如果复用页面本身已经属于本轮授权输出范围，可以按用户要求原位修改；否则只把来源作为只读基线，在目标范围内复制或重建。

## 参考门禁（`Reference Gate`）

UX 任务职责明确前不打开业务案例反推需求。基础设备模板、规范和能力边界可提前只读；明确职责后允许同类现网模式作为证据，但必须回查 PRD，不能复制结论。

UX 冻结后、组件解析前，必须完成 `referenceReview`，不能把现有页面复用、Template 匹配或参考读取留成可选建议：

- 先枚举原输入文件的顶层页面并记录 `existingPageScan`，寻找可接入当前流程的现有页面；命中页面可作为前置/后续步骤，也可作为新增页面的壳层、导航、状态和内容连续性提示。
- 再按 [元宝移动端配置](yuanbao-mobile-configuration.md) 读取精确页名 `【AI参考案例】Template`，检查页面内部名称或流程相近的子节点；命中时决定直接复用、改造复用或仅参考。
- 最后读取用户请求/PRD 中给出的 Figma 参考 URL 或附件；用户已经提供链接时直接使用，不再次问用户要链接。
- 只打开与已冻结主模式同类的允许参考；
- 命中页面使用页面级决策：任务、步骤和状态一致且只调整流程位置时记 `direct-reuse`；复用壳层/流程但要改内容、状态或布局时记 `adapt-reuse`；只借鉴局部时记 `reference-only`；
- 每项记录 `matched / no-match / not-applicable`、理由和 `kind=reference` 工具证据；命中项另记 `reuseAction / unitIds / changeScope`；没有同类就记录 `no-match`，不硬套其它页面；
- 与 PRD 冲突时以 PRD 为准；要改需求则重新冻结；
- 现有页面和组件库 Template 都可以成为业务稿实现起点；来源页只读，需要独立版本时只在授权目标内复制/重建。正式资产仍通过现场组件解析获取，不能把来源页里的旧实例直接当作正式资产身份。
- 页面复用不能替代组件复用阶梯；复制后仍逐个核对 `liveLibrary` 身份、公开属性和保护字段。
- 参考读取失败且用户明确要求使用该参考，或现有页面/Template 的当次读取能力不可用时，记录阻断并暂停相关方案阶段；不能靠让用户重贴链接绕过。

## 禁止

- 打开范围外历史 AI 页“看看错误长什么样”；
- 从来源页 detach 图层、解绑变量、复制偶然数值或把旧实例身份直接当正式资产身份；页面复用时保留正式实例关系，正式身份必须重新核对；
- 在组件库 Template、Cover 或规范源上创建、修改业务稿；
- 让现有页面或 Template 覆盖 PRD、决定业务写入文件或替代现场组件解析；
- 把参考文案、调试标注或单次间距升级为团队规范。

## 写入目标

- `generate` 且含 Figma：按配置新建业务页。
- `iterate` / `review-existing` / `independent-review`：只进入用户或交接包指定目标。
- 新增业务 Frame、说明和真实缺口最终按 [canvas-organization.md](canvas-organization.md) 整理。
