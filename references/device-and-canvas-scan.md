# 设备与画布现场扫描

仅在 PRD 未确定设备、画布或正式模板时使用。扫描结果只进入本次 Screen Spec，不写回全局规则。

## 1. 扫描来源

- 目标文件：只扫描本轮目标页；设计结构优先复用原输入文件同类现有页面，其次读取组件库 `【AI参考案例】Template` 的同类子流程。
- 规范源：只读搜索正式设备/画布模板和本轮已解析组件自己的样例。
- iPad：`search_design_system` 搜 `ipad 模板`，读取组件集 description；断点和主区规则搜 `iPad适配规则` 规范说明组件。不要把断点或主区宽度抄进 Skill，也不要把规范说明组件实例化到业务稿。
- 页面外层间距：搜 Spacing 变量并打开 `间距规范` 画板；正式组件内部间距仍跟该组件走。
- 页名与读法见 [foundations/index.md](foundations/index.md)。
- 禁止进入范围外历史 AI 页。

## 2. 记录

- 节点名称、ID、宽高和设备类别；
- 页面背景和主题模式；
- 安全区、滚动、overlay 和自适应方式；
- 主要正式实例及其现场 key；
- 是否存在 detach、自绘替代或调试标注。

## 3. 选择

- 优先 PRD 明确的平台和设备；
- 其次使用规范源正式模板：iPad 画布用 `ipad 模板` 的竖屏或横屏，布局规则读 `iPad适配规则` 规范说明组件；
- 再用同类目标稿中的高频尺寸作为线索；
- 无证据时向用户确认，不用历史常量猜，也不要拉伸手机画布。

## 4. 使用边界

- 尺寸、安全区和适配策略进入本次冻结包；
- 组件用法仍走现场组件解析；
- 偶然文案、坐标、detach 图层和演示尺寸不得升级为规范；
- 新设备或窗口变化必须重新扫描。
